# 🛍️ Q.hobby (কিউ.হবি) - প্রিমিয়াম অনলাইন শৌখিন ই-কমার্স প্ল্যাটফর্ম

**Q.hobby** হলো একটি আধুনিক, দৃষ্টিনন্দন এবং পূর্ণাঙ্গ কার্যক্ষম ই-কমার্স প্ল্যাটফর্ম। এখানে ক্রেতারা সহজেই শৌখিন পণ্য, হস্তশিল্প সামগ্রী, হোম ডেকোর ও উপহার আইটেম ব্রাউজ ও সরাসরি WhatsApp এ অর্ডার করতে পারেন। সম্পূর্ণ ডাটাবেস গিটহাবে (GitHub JSON DB) সংরক্ষিত থাকে এবং Vercel-এর মাধ্যমে স্বয়ংক্রিয়ভাবে ২৪/৭ লাইভ রান করে।

## 📁 প্রজেক্ট ফোল্ডার স্ট্রাকচার (Clean Architecture)

```
Qhobby/
├── index.html                   # মূল অ্যাপ্লিকেশন এন্ট্রি পয়েন্ট
├── vercel.json                  # Vercel ডিপ্লয়মেন্ট ও ক্যাশিং কনফিগারেশন
├── README.md                    # প্রজেক্ট গাইড ও ডকুমেন্টস
│
├── assets/                      # স্ট্যাটিক অ্যাসেটস
│   ├── css/
│   │   └── style.css            # গ্লাস মরফিজম, অ্যানিমেশন ও ডার্ক থিম সিএসএস
│   └── js/
│       ├── config.js            # গ্লোবাল কনফিগারেশন ও ধ্রুবক
│       ├── github-db.js         # গিটহাব JSON ডাটাবেস ইঞ্জিন (CRUD + GitHub Commit API)
│       ├── public-panel.js      # পাবলিক স্টোর: প্রোডাক্টস, ফিল্টারিং, অর্ডার ও অভিযোগ
│       ├── user-panel.js        # ইউজার প্যানেল: কাস্টমার একাউন্ট, অর্ডার ট্র্যাকিং ও উইশলিস্ট
│       ├── admin-panel.js       # এডমিন প্যানেল: KPI মেট্রিক্স, প্রোডাক্ট CRUD, Q Data শীট
│       └── app.js               # প্যানেল নেভিগেশন ও গ্লোবাল মডাল/টোস্ট অর্কেস্ট্রেটর
│
└── data/                        # 🗄️ গিটহাব ডাটাবেস ফাইলসমূহ (JSON Database)
    ├── products.json            # সকল প্রোডাক্টের তালিকা (PI, মূল্য, স্টক, ছবি)
    ├── culture.json             # Q Hub আপডেট, নোটিশ ও কমিউনিটি স্টোরি
    ├── orders.json              # Q Data গ্রাহক অর্ডারসমূহ (অর্ডার হিস্টোরি)
    ├── complaints.json          # গ্রাহক অভিযোগের রেকর্ড
    └── site-config.json         # সাইটের সাধারণ সেটিংস ও WhatsApp নম্বর
```

## 🌟 ৩টি প্যানেলের ফিচারসমূহ (3 Panels Architecture)

### ১. পাবলিক প্যানেল (Public Store Panel)
- **হিরো ব্যানার ও ব্র্যান্ডিং**: দৃষ্টিনন্দন নিয়ন গ্রেডিয়েন্ট ও গ্লাস মরফিজম।
- **শপ ও ফিল্টারিং**:
  - ক্যাটাগরি ফিল্টার (হস্তশিল্প ও আর্ট, হোম ডেকোর, শৌখিন সামগ্রী, উপহার)।
  - মূল্য সীমা ফিল্টার (৫০৳, ১০০৳, ৩০০৳, ৫০০৳, ৮০০৳ মধ্যে)।
  - লাইভ সার্চ (নাম ও Product ID (PI) দ্বারা)।
- **প্রোডাক্ট ডিটেইলস মডাল**: ভেরিফাইড সেলার প্রোফাইল, ডেলিভারি পার্টনার্স (Pathao, Steadfast, Sundarban), কুপন কোড ও ৭ দিনের রিটার্ন পলিসি।
- **অর্ডার ও গিফট সিস্টেম**:
  - গ্রাহকের নাম, WhatsApp নম্বর, বিকল্প নম্বর ও ঠিকানা।
  - ডায়নামিক ক্যালকুলেটর ও ১৮+ শর্তাবলী সম্মতি।
  - স্বয়ংক্রিয়ভাবে WhatsApp এ মেসেজ জেনারেট এবং ডাটাবেসে সেভ।
- **সেলার ভেন্ডর ফর্ম ("আপনার পণ্য বিক্রি করুন")**: সেলার শর্তাবলী ও WhatsApp আবেদন।
- **কমপ্লেইন ফর্ম ("অভিযোগ পাঠান")**: সেলার আইডি সহ সরাসরি অভিযোগ সাবমিট।

### ২. ইউজার প্যানেল (User / Customer Account Panel)
- **সহজ মোবাইল লগইন**: কোনো পাসওয়ার্ডের ঝামেলা ছাড়াই মোবাইল নম্বর দিয়ে কাস্টমার পোর্টাল অ্যাক্সেস।
- **আমার অর্ডারসমূহ (Order History & Tracking)**:
  - লাইভ স্ট্যাটাস ট্র্যাকার: 🟡 Pending &rarr; 🔵 Confirmed &rarr; 🟣 Shipped &rarr; 🟢 Delivered।
  - প্রতিটি অর্ডারের সাথে সরাসরি WhatsApp সাপোর্ট লিঙ্ক।
- **উইশলিস্ট (Wishlist)**: প্রিয় পণ্যগুলো এক ক্লিকে সংরক্ষণ ও ক্রয়।
- **অটো-ফিল প্রোফাইল**: ডিফল্ট ডেলিভারি ঠিকানা সেভ রাখা যায়।

### ৩. এডমিন প্যানেল (Admin Controller & Q Data)
- **পাসওয়ার্ড নিরাপত্তা**: সুরক্ষিত এডমিন অ্যাক্সেস (ডিফল্ট: `admin123`)।
- **KPI এক্সিকিউটিভ ওভারভিউ**: মোট প্রোডাক্ট, মোট অর্ডার, মোট আয় (৳), পেন্ডিং অর্ডার ও অভিযোগ কাউন্টার।
- **প্রোডাক্ট ম্যানেজার (CRUD)**: নতুন প্রোডাক্ট যোগ, এডিট, ডিলিট, ছবি আপলোড এবং স্টক পরিবর্তন।
- **Q Hub ম্যানেজার**: নতুন নোটিশ ও কালচার আপডেট পোস্ট করা।
- **Q Data স্প্রেডশীট (Orders Sheet)**:
  - সকল অর্ডারের রিয়েল-টাইম টেবিল।
  - ড্রপডাউন দিয়ে অর্ডার স্ট্যাটাস তাৎক্ষণিক পরিবর্তন।
  - **Export to Excel (CSV)**: এক ক্লিকে বাংলা ফ্রেন্ডলি এক্সেল ফাইল ডাউনলোড।
- **কমপ্লেইন ম্যানেজার**: কাস্টমারদের অভিযোগ দেখা ও সমাধান করা।
- **গিটহাব ডাটাবেস সিঙ্ক সেন্টার**:
  - ব্রাউজার থেকেই সরাসরি GitHub API এর মাধ্যমে `data/*.json` ফাইল কমিট করা যায়।
  - গিটহাবে কমিট হওয়া মাত্রই Vercel স্বয়ংক্রিয়ভাবে রিডিপ্লয় করে সবসময় লাইভ রাখে!
  - অফলাইন JSON ব্যাকআপ ডাউনলোড ও রিস্টোর।

## 🚀 GitHub ও Vercel এ ডিপ্লয়মেন্ট পদ্ধতি (Always Run 24/7)

### ধাপ ১: GitHub এ পুশ করুন
```powershell
git add .
git commit -m "feat: complete Q.hobby modular architecture with 3 panels and GitHub DB"
git push -u origin main
```

### ধাপ ২: Vercel এ কানেক্ট করুন
1. [vercel.com](https://vercel.com) এ লগইন করুন।
2. **Add New...** &rarr; **Project** সিলেক্ট করুন।
3. আপনার GitHub একাউন্ট থেকে **`eQro-sit/Q.hobby-1`** (বা আপনার রিপোজিটরি) ইমপোর্ট করুন।
4. Framework Preset: **Other** (বা Static HTML)।
5. **Deploy** বাটনে ক্লিক করুন।
